# Automatizador de Fichas

Executável Python (one‑file) com interface gráfica para:
- Carregar, visualizar e editar JSON de ficha clínica
- Exibir perguntas detectadas no JSON, permitir edição de textos (forçando UPPERCASE) e alteração de booleanos via checkbox
- Gerar script SQL de perguntas (com opções configuráveis posteriormente) e visualizar/baixar/copiar
- Gerar SELECT SQL para Jasper Reports (baseado no padrão ouro) e visualizar/baixar/copiar
